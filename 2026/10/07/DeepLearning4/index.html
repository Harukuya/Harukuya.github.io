2.2 生成模型

2.2.0 生成模型在学什么（家族公共部分）

2.2.0 生成路线
2.2.0 生成路线

判别模型学「给定输入，输出是什么」：p(y | x)，或者干脆只给一个确定的 ŷ。生成模型学数据本身的分布 p(x)（或者带条件的 p(x | c)），学会之后可以：

  • 采样：造出训练集里没有、但看起来属于同一分布的新样本（图像、语音、分子、机器人动作）
  • 评估似然：给样本算一个概率密度，可以辅助异常检测。但在高维数据上，分布外样本有时反而得到更高的似然（Nalisnick 2019），密度高低不能直接当成「像不像」训练数据
  • 补全：已知一部分，生成其余部分（图像修复、轨迹补全）

为什么不用回归代替：1.4 节说过，MSE 回归学到的是条件均值。同一个条件下有几个都正确的答案时，均值可能落在答案之间的低概率区域，也可能靠近其中一个（2.10.2）。另一个更隐蔽的问题是弯曲的合法区域：一段 16 步 × 7 维的机械臂动作是 112 维空间里的一个点，合法的动作常常只占其中一片弯曲的区域。区域是弯的（非凸）时，两个合法点的平均可能落到区域外面（下面代码里的圆演示的就是这种非凸区域），即使分布只有一个峰也可能这样；避障、逆运动学这类约束都会造成这种情况。如果约束只有关节上下限、每步速度上限这类凸约束，合法轨迹的平均仍然合法，这个问题就不出现。生成模型输出的是一次采样，学得好时会落在某个具体的峰上、落在合法区域里；但有限的模型和有限的采样步数仍可能给出低概率甚至不合法的结果，生成模型并不保证输出物理可执行。

为什么扩散能处理多峰和流形

  1. 随机起点：不同的初始噪声被引导到不同的峰。在低噪声、两个峰还分得开的阶段，score 在峰之间的谷底指向两边，把样本推向两侧（正中间的对称点上 score 可能恰好为 0）；高噪声阶段的 score 对应的是平滑后的分布，两个峰可能还没分开。理想的模型和精确的采样能恢复目标分布，落在谷底的比例和真实分布在那里的概率相当；有限的模型和离散步长会带来误差
  2. 学会往流形上拉：训练时故意把数据推离流形（加噪），再教网络推回来。网络在流形周围整个邻域都学到了「从这里该往哪走」，效果接近一个往数据上拉的投影
  3. 有监督的迭代：推理时迭代几十步，相当于把网络加深了几十倍，而每一步在训练时都有明确的目标（知道加了多少噪声，就知道该预测什么）。普通深网络加深容易训崩，扩散把深度换成了噪声等级，每一级单独监督

去噪步 t 和真实时间是两根轴：在机器人策略里，真实时间 t 是机器人走到第几步；去噪步（论文里常写 τ 或 k）是一次生成内部迭代到第几轮。策略每重新规划一次，去噪步就从 T 到 0 完整跑一遍，生成一整块动作。Diffusion Policy 默认执行完其中 8 步再重新规划（3.2.2），只有每块只执行 1 步时，才是每走一步完整去噪一次。网络必须知道当前去噪步，因为「刚开始去噪」要大刀阔斧，「快去完了」只能微调，所以 τ 要做成嵌入向量喂给网络。

常用扩展

扩展 做什么
DDIM 确定性采样（η = 0 时），可以把上千步压到几十步；步数越少质量下降越明显，下降多少取决于模型、数据和步数
无分类器引导（CFG） 训练时随机丢掉条件，同时学有条件和无条件；采样时用 ε̃ = ε_无条件 + w·(ε_有条件 − ε_无条件)，w > 1 让结果更贴合条件
潜空间扩散（Stable Diffusion） 先用 VAE 把 512×512 的图压成 64×64×4 的隐变量，在隐空间做扩散，计算量降几十倍

典型例子

  • 图像生成：DALL·E 2、Imagen、Stable Diffusion（潜空间扩散）、Midjourney 一类产品
  • 视频生成：Sora 等，用 Transformer 当去噪网络（DiT）
  • 音频：DiffWave；分子与蛋白质设计：RFdiffusion；天气：GenCast
  • 机器人：Diffusion Policy（Chi 2023）把一段动作序列当成要生成的「图像」，以观测为条件去噪出 16 步动作，从当前时刻对应的位置起执行 8 步再重新观测；同一个观测下「从左绕」和「从右绕」两种演示都能学到，不会平均成撞上去
  • 优势：能覆盖多峰分布，不容易模式塌缩；训练目标就是回归噪声，非常稳定；样本质量高；条件生成灵活（CFG、修补、编辑都能做）
  • 局限：采样要迭代几十到上千步，推理慢（DDIM、蒸馏、一致性模型、Flow Matching 都在压这个成本）；DDPM 的对数似然通常用变分下界（ELBO）来估计，实际训练用的简化 MSE 去掉了 ELBO 里随 t 变化的权重，不能直接当作对数似然的下界；连续时间的 score 模型还能沿概率流 ODE 算出模型密度，要数值积分，代价高
  • 适合的数据：连续、高维、多峰的数据：图像、视频、音频、3D 形状、分子构型、机器人动作序列

2.2.2 Flow Matching

2.2.2 Flow Matching
2.2.2 Flow Matching

一句话

选一条从噪声到数据的路径（最常用的是直线），让网络学这条路径上每一点的速度；生成时从噪声出发，沿学到的速度场积分到数据。

训练（本节用直线路径，也就是 Rectified Flow 的写法）：x_0 是噪声，x_1 是数据，两者随机配对，t 在 0 到 1 之间均匀采样。直线路径上的点和速度：

生成：从 x_0 ~ N(0, I) 出发，用欧拉法解常微分方程 dx/dt = v_θ(x, t)，走几步到几十步。

和扩散的关系：两者都是「把噪声分布搬运到数据分布」。Flow Matching 是一个框架：先指定一条概率路径，再回归这条路径对应的速度场；路径也可以选扩散那样的加噪路径，这时学到的就是扩散的概率流 ODE。这里用的直线路径没有加噪日程，采样是确定性的 ODE。单条样本对的路径是直的，但噪声和数据随机配对时，网络学到的是条件平均速度：在 t = 0 处它正好等于 E[x_1] − x_0，从起点走一整步就落到数据的均值上（下面代码里能看到）。这和数据是不是多峰无关，单峰时也会塌到均值、丢掉方差，多峰时均值落在峰之间，问题更显眼。学到的速度沿途随位置和时间变化，流线一般也是弯的，起点的速度不能代表整段位移，所以要细分步长才能跟住。Rectified Flow 的 reflow、蒸馏可以进一步把流线拉直，实现一两步生成。

常见说法与实测

常见说法：Flow Matching 学的是直线路径，所以只要很少的步数，甚至一步就能生成。

实测：8 个高斯团的数据上（噪声和数据随机配对，没做 reflow），积分 1 步时样本全部挤在圆心附近（到原点的平均距离 0.33，目标是 2）；2 步时只有 15% 落在半径 2 的圆环附近；5 步 99%；20 步 100%。这个指标只看半径，圆环上团与团之间的样本也算进去，所以它说明的是「回到了圆环上」，不是「命中了团」。

怎么理解：「直线」指的是训练时每一对（噪声、数据）之间连的那条线。同一个噪声点在训练中会和很多不同的数据点配对，网络学到的是这些方向的条件平均：在起点 t = 0 处就是「指向数据均值」，所以一步正好走到均值，这一点和是否多峰无关；之后速度随位置和时间变化（合起来的流线一般也是弯的），要多走几步才能跟住。要一两步就生成，常用 Rectified Flow 的 reflow（用模型自己生成的配对重新训练，把流线拉直）或者蒸馏。

典型例子

  • 图像：Stable Diffusion 3、Flux 用的是 Rectified Flow
  • 视频与语音：Meta 的 Movie Gen、Voicebox
  • 机器人：π0 的动作专家用 Flow Matching 生成连续动作块，动作按最高 50 Hz 执行（重新生成动作块的频率更低）
  • 优势：用直线路径时训练目标很简单（没有加噪日程和各种参数化选择）；路径较直，采样步数通常比扩散少；确定性 ODE，便于反演和蒸馏
  • 局限：少步采样时有离散化误差；随机配对、不做 reflow 或蒸馏时，从起点一步生成会塌到数据均值附近（和是否多峰无关，多峰时更显眼）；理论上和扩散的很多结论可以互相转换，选哪个更多是工程偏好
  • 适合的数据：与扩散模型相同；尤其适合对推理延迟敏感的连续生成，比如高频机器人控制

2.2.3 VAE 变分自编码器 〔图：VAE〕

2.2.3 VAE
2.2.3 VAE

一句话

编码器输出一个分布（均值和方差），从中采样隐变量再解码；损失 = 重建误差 + 让这个分布贴近标准正态的 KL 项，于是隐空间连续、可以采样生成。

和普通自编码器的区别（自编码器见 2.6.4）：普通 AE 把输入编码成一个点，隐空间里点与点之间是空的，随便取一个点解码出来往往是垃圾。VAE 把输入编码成一个高斯分布 N(μ, σ²)，并用 KL 项把所有这些小分布拉向 N(0, I)，鼓励隐空间被填满、连续，从 N(0, I) 采样解码通常能得到合理的新样本（不保证先验里的每一点都解码得好）。

这个损失的相反数是对数似然的一个下界，叫 ELBO（证据下界）。

重参数化技巧：把「从分布里采样」当成一个黑盒调用时，抽出来的 z 和 μ、σ 之间没有可以求导的路径，梯度回不到编码器。改写成 z = μ + σ ⊙ ε，ε ~ N(0, I)，随机性挪到了与参数无关的 ε 上；固定这次抽到的 ε，z 对 μ、σ 就可导，梯度可以穿过 μ 和 σ 回传给编码器。PyTorch 分布对象的 rsample() 就是这种写法（sample() 不保留梯度），下面的代码直接手写了这一行。

  • Stable Diffusion 的第一步：VAE 把图像压到 1/8 分辨率的隐空间

  • 局限：样本偏模糊（高斯似然 + 重建误差的平均效应）；解码器太强时会忽略 z（后验坍塌）；ELBO 只是下界
  • 适合的数据：需要一个规整隐空间的数据：图像、分子、轨迹、传感器序列；把数据压到隐空间供下游（世界模型、扩散）使用

2.2.4 GAN 生成对抗网络 〔图：GAN〕

2.2.4 GAN
2.2.4 GAN

一句话

生成器把噪声变成假样本，判别器区分真假；两者对抗训练，直到判别器分不出来。

图中左半是生成器，右半是判别器，中间那一列是生成器的输出（它要模仿真实数据，所以画成输入输出匹配单元）。

交替训练：先固定 G，训练 D 把真样本判 1、假样本判 0；再固定 D，训练 G 让 D 把假样本判成 1。实践中 G 的损失用 −log D(G(z))（非饱和形式），训练初期梯度更大。

两个老问题

问题 现象 常见对策
训练不稳定 一方压倒另一方，损失震荡或发散 谱归一化、WGAN-GP（换成 Wasserstein 距离 + 梯度惩罚）、调学习率比例
模式塌缩 生成器只会产出少数几种样本，判别器发现后它换另一种，来回打转 小批量判别、多样性损失、WGAN 类目标。目标本身在理想条件下要求匹配整个分布（原论文证明全局最优就是生成分布等于数据分布），塌缩来自有限容量、交替优化的动力学和梯度性质

主要变体：DCGAN（卷积结构的标准配方）、条件 GAN、pix2pix（成对图像翻译，生成器是 U-Net）、CycleGAN（不成对的图像翻译，循环一致性）、StyleGAN（风格调制，高质量人脸）、SRGAN（超分辨率）。

常见说法与实测

常见说法：GAN 容易模式塌缩，只会生成少数几种样本。

实测：两边学习率相同（都是 1e-3）时，8 个团的扇区都有样本，各扇区样本数相近（按角度划分扇区，没检查样本离团中心多近）；把判别器的学习率降到 1e-4，样本挤在一两个扇区里。另外换 4 个随机种子重复（同样按扇区统计）：学习率相同时 4 次都是 8 个扇区全有样本，判别器学习率降低后 4 次样本都挤在少数扇区里。

怎么理解：在这个例子里，塌缩会不会发生取决于两边学习率的平衡：判别器跟不上时，生成器只要找到一处能骗过它的区域就够了，没有动力去覆盖其他团。这只是触发塌缩的一种方式，模型容量、梯度性质和其他超参也会导致塌缩。「容易塌缩」说的是实践中常见，并没说每次都会发生；高维图像上维持这种平衡难得多，所以塌缩更常见。

典型例子

  • 人脸生成：StyleGAN 系列（「这个人不存在」网站）
  • 图像翻译：pix2pix（草图 → 照片）、CycleGAN（马 → 斑马）
  • 超分辨率：SRGAN
  • 模仿学习：GAIL 把判别器用来区分「专家的状态-动作」和「策略的状态-动作」，策略当生成器
  • 仿真到真实：GraspGAN 把仿真图像翻译得像真实图像，减少机器人抓取所需的真实数据
  • VQGAN、潜空间扩散的 VAE 训练时还保留判别器，提供让图像更锐利的对抗损失（感知损失 LPIPS 是另外一项）
  • 优势：样本锐利、细节真实；生成只要一次前向，快；不需要显式写出似然；判别器的思路可以挪作他用（对抗损失、域适应、模仿学习）
  • 局限：训练不稳定、超参敏感；模式塌缩，多样性差；没有编码器，拿不到样本的隐表示；没有似然，难评估；在图像生成主流上已被扩散取代
  • 适合的数据：需要高保真、单次快速生成的连续数据：图像、音频；成对或不成对的图像翻译；以「分布对齐」为目标的问题（模仿学习、域适应）

2.2.5 VQ-VAE 向量量化自编码器

2.2.5 VQ-VAE
2.2.5 VQ-VAE

一句话

编码器输出的每个向量都替换成码本里离它最近的那个码字，连续信号就变成了一串离散 token。

项 谁在动 作用
码本项 码本 把选中的码字拉向编码器输出

直通估计：argmin 不可导。前向用 z_q，反向时把解码器传回来的梯度原样交给 z_e，代码里写成 z_q = z_e + (z_q − z_e).detach()。

量化带来的好处

  1. 数据变成离散 token，可以交给 Transformer 像语言一样自回归生成，或者和文字 token 放进同一个模型
  2. 离码字分界面较远时，小扰动不会改变最近的码字，对传感器噪声更鲁棒（落在分界面附近时，很小的扰动也会换码字）
  3. 压缩：一张图变成几百到上千个整数（VQGAN 把 256×256 的图压成 16×16 = 256 个 token）

码本塌缩：大部分码字从来没被选中过，有效码本很小。对策：码本用 EMA 更新、定期把死码重置为当前的编码器输出、降低码字维度后再查表。后续变体：残差向量量化 RVQ（多级码本逐级量化残差，音频编解码器常用）、有限标量量化 FSQ（每维直接取整，没有码本塌缩问题）。

典型例子

  • 图像：VQ-VAE-2、VQGAN（加了对抗损失和感知损失），把图像变成 token 后用 Transformer 生成
  • 音频：SoundStream、EnCodec 用残差向量量化，产出的音频 token 供 AudioLM 等语言模型使用
  • 机器人：VQ-BeT 把动作量化成离散码再预测；触觉和力的历史也可以压成 token 交给 Transformer
  • 多模态大模型里的图像 tokenizer
  • 优势：把任意连续信号变成离散 token，接上 Transformer 生态；不容易出现 VAE 那种后验坍塌；表示紧凑，对小噪声鲁棒
  • 局限：码本塌缩，需要额外技巧；量化有信息损失；直通估计是近似，码本大小 K 是需要调的硬超参
  • 适合的数据：需要离散化的连续数据：图像、音频、视频、动作轨迹、触觉/力信号；多模态模型的 tokenizer

2.2.6 标准化流

一句话

用一串可逆变换把简单分布（高斯）变成复杂分布；因为可逆，每个样本的概率密度都能精确算出来。

难点在雅可比行列式：一般矩阵的行列式是 O(D³)。标准化流的设计就是让每一层既可逆、行列式又好算。

仿射耦合层（RealNVP）：把维度分成两半，前一半原样通过，并用它算出后一半的缩放 s 和平移 t：

雅可比是三角矩阵，log|det| = Σ s；求逆只要反过来减 t、除 exp(s)，s 和 t 本身可以是任意复杂的网络。多层交替换「哪一半不动」，就能变换所有维度。

典型例子

  • Glow（2018）：可逆网络生成人脸，隐空间可以做属性编辑
  • WaveGlow：语音合成里把梅尔频谱变成波形
  • 物理与化学：Boltzmann Generator 用流对分子构型做采样，能直接算每个构型的概率密度
  • 异常检测：用对数密度当异常分数（高维图像上要先验证，分布外样本可能得到更高的似然）
  • 变分推断里的灵活后验（IAF 等）
  • 优势：精确的对数似然；耦合流（RealNVP、Glow）编码和生成都是确定的一次前向；最大似然训练，稳定
  • 局限：可逆约束要求每层输入输出维度相同，模型要很大才能达到扩散/GAN 的样本质量；结构设计受「行列式好算」限制；自回归流两个方向的速度不对称：MAF 算密度一次前向、采样要逐维，IAF 采样一次前向、给外部数据算密度要逐维
  • 适合的数据：需要精确概率密度的连续数据：中低维的物理状态、分子构型、音频；密度估计与异常检测

2.2.7 DCIGN 深度卷积逆图形网络 〔图：DCIGN〕

2.2.7 DCIGN
2.2.7 DCIGN

一句话

卷积编码器 + 概率隐变量 + 反卷积解码器（本质是卷积版 VAE），训练时让隐变量的每几维专门对应一个图形学参数（姿态、光照），于是可以只改一个参数重新「渲染」图像。

名字的意思：图形学是「场景参数 → 图像」（渲染）；逆图形学是「图像 → 场景参数」。DCIGN（Kulkarni 2015）的编码器做逆图形，解码器做渲染。

训练技巧：数据按「每个 batch 只有一个因素在变」来组织（比如一批图只有方位角在变，光照和形状都固定）。前向时，除了负责这个因素的那几维，其余隐变量都替换成这个 batch 的平均值，逼解码器只能用指定的那几维解释这批图像之间的差异；同时让其余维度在 batch 内保持不变。训练完成后，隐变量的各维有了明确语义。

DCIGN隐变量遍历
DCIGN隐变量遍历

典型例子

  • 论文里的实验：从一张人脸照片推出姿态、光照、形状参数，再只改方位角，重新渲染出同一张脸转头后的样子
  • 这条思路后来发展成「解耦表示学习」（β-VAE 等）和「分析-合成」式的三维重建（NeRF 一类可微渲染）
  • 优势：隐变量有明确的物理/图形学语义，可以单独控制；编码器 = 反渲染器，解码器 = 渲染器
  • 局限：需要「每批只变一个因素」的数据，通常只有合成渲染数据能满足；样本质量受 VAE 模糊问题限制；现在很少直接使用
  • 适合的数据：生成因素已知、可以受控采集的图像：合成渲染数据、三维物体多视角图像、受控光照人脸
